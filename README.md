# Water Pipes of Farawayland

A browser-based puzzle game created for a Web Programming course assignment using HTML, CSS, and JavaScript.

## Overview

The goal of the game is to rotate the pipe tiles to create a valid water network from the source to all consumer pipes.

The game includes:
- Multiple difficulty levels
- Randomized pipe rotations
- Water flow checking
- Win condition validation
- Timer
- Save/load functionality
- Leaderboard system

## Technologies Used

- HTML
- CSS
- JavaScript
- LocalStorage API

## Features

### Start Screen
- Player name input
- Difficulty selection
- Leaderboard display
- Continue saved game option
- Game rules

### Game Screen
- Dynamic timer
- Interactive pipe rotation
- Water flow visualization
- Solution checking
- Save game functionality
- Leaderboard saving

## How to Run

1. Download or clone the repository
2. Open `index.html` in a browser
